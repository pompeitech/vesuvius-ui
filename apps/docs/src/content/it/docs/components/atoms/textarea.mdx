# Textarea

Un `<textarea>` nativo stilizzato.

```tsx
import { Textarea } from "@pompeitech/vesuvius-ui";
```

## Dimensione fissa (senza maniglia di ridimensionamento)

La maniglia di ridimensionamento predefinita del browser è attiva — disattivala con `resize-none` quando un layout fisso conta più che permettere all'utente di ridimensionare:

<ComponentPreview code={`<Textarea placeholder="Fixed height, no resize handle." className="resize-none" />`}>
  <Textarea placeholder="Altezza fissa, nessuna maniglia di ridimensionamento." className="max-w-sm resize-none" />
</ComponentPreview>

## API

**Textarea**

Ogni prop nativa di `<textarea>`, incluse `ref`, `rows` e `maxLength`.

| Prop | Tipo | Descrizione |
| --- | --- | --- |
| `rows` | `number` | Altezza visibile in righe di testo. |
| `maxLength` | `number` | Limite nativo di caratteri, imposto dal browser. |
| `disabled` | `boolean` | |

Nessun extra — il componente aggiunge solo stile, nessun comportamento di auto-ridimensionamento al contenuto (aggiungilo tu stesso tramite una libreria come `react-textarea-autosize` se ti serve; `Textarea` inoltra `ref`, quindi si compone direttamente con una).

### Accessibilità

Come [`Input`](/docs/components/atoms/input) — abbina sempre a una `<Label htmlFor>` o `aria-label`.
