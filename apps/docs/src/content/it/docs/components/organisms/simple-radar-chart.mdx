# Simple Radar Chart

Un grafico radar [Recharts](https://recharts.org/) a partire da dati tabellari — nessun collegamento manuale di `ChartContainer`/config necessario, stessa forma condivisa del resto della famiglia di grafici.

```tsx
import { SimpleRadarChart } from "@pompeitech/vesuvius-ui";
```

## API

**SimpleRadarChart**

| Prop | Tipo | Default | Descrizione |
| --- | --- | --- | --- |
| `data` | `Record<string, any>[]` | | Obbligatorio. |
| `index` | `string` | | Obbligatorio — la chiave che contiene l'etichetta di ogni raggio. |
| `categories` | `string[]` | | Obbligatorio — chiavi tracciate come serie; più di una sovrappone più forme radar. |
| `colors` | `string[]` | i token `--chart-1`…`--chart-5` del tema | Un colore per categoria, in ordine. |
| `showLegend` | `boolean` | `true` | |

Più ogni prop nativa di `<div>` sul wrapper radice.
