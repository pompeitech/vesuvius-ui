# Form Helper Text

Testo di aiuto a livello di campo con uno stato — info/success/warning/error, non solo neutro-o-errore come le semplici descrizioni di form. Dentro un `FormField` gestito da RHF, preferisci [`FormMessage`](/docs/components/molecules/form) (renderizza automaticamente l'errore di validazione effettivo); usa questo quando ti servono stati di successo/info, o un testo di aiuto fuori da quel contesto.

```tsx
import { FormHelperText } from "@pompeitech/vesuvius-ui";
```

## API

**FormHelperText**

| Prop | Tipo | Default | Descrizione |
| --- | --- | --- | --- |
| `variant` | `"default" \| "info" \| "success" \| "warning" \| "error"` | `"default"` | Imposta sia il colore del testo che l'icona iniziale. |
| `showIcon` | `boolean` | `true` | Ignorato per `"default"`, che non ha comunque icona. |

Più ogni prop nativa di `<p>`.

### Accessibilità

Colorazione/iconografia puramente visiva — non porta un proprio ruolo ARIA. Quando abbinato a un campo fuori da RHF, associalo tramite `aria-describedby` che punta al suo `id` così la tecnologia assistiva lo legge insieme al campo; dentro un `FormField` di RHF, preferisci `FormMessage`/`FormDescription`, che collegano tutto questo automaticamente.
