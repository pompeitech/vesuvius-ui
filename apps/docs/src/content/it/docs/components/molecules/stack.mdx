# Stack

Un primitivo di layout flexbox con prop responsive di prima classe — "dammi una riga che si impila in una colonna su mobile." Si abbina a [`Grid`](/docs/components/molecules/grid).

```tsx
import { Stack } from "@pompeitech/vesuvius-ui";
```

## Colonna (default)

    {[1, 2, 3].map((i) => <div key={i} className="flex size-16 items-center justify-center rounded-md bg-accent text-sm">{i}</div>)}

## API

**Stack**

| Prop | Tipo | Default | Descrizione |
| --- | --- | --- | --- |
| `direction` | `"row" \| "column" \| "row-reverse" \| "column-reverse"`, o `{ base?, sm?, md?, lg?, xl? }` di questi | `"column"` | Responsive quando fornito nella forma a oggetto per breakpoint. |
| `align` | `"start" \| "center" \| "end" \| "stretch" \| "baseline"` | | Corrisponde ad `align-items`. |
| `justify` | `"start" \| "center" \| "end" \| "between" \| "around" \| "evenly"` | | Corrisponde a `justify-content`. |
| `gap` | numero della scala di spaziatura Tailwind, o `{ base?, sm?, md?, lg?, xl? }` di questi | `0` | Responsive allo stesso modo di `direction`. |
| `wrap` | `boolean` | `false` | Corrisponde a `flex-wrap: wrap`. |

Più ogni prop nativa di `<div>`.
