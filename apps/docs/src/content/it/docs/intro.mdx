# Vesuvius UI

Vesuvius UI è un kit di componenti React + TypeScript completo, costruito sui primitivi di [Radix UI](https://www.radix-ui.com/) e stilizzato con [Tailwind CSS v4](https://tailwindcss.com/). Viene distribuito come un singolo pacchetto, `@pompeitech/vesuvius-ui`, con:

- **65+ componenti**, organizzati (seguendo l'[Atomic Design](https://atomicdesign.bradfrost.com/chapter-2/)) come [atomi](/docs/components/atoms), [molecole](/docs/components/molecules) e [organismi](/docs/components/organisms).
- **10 temi colore integrati** (Lava, Stripe, Vercel, Supabase, Linear, Claude, Amber Minimal, Claymorphism, Alpine, Aubergine), ognuno con modalità chiara/scura indipendente.
- **Accessibilità gratuita**, ereditata dai primitivi non stilizzati di Radix UI sotto ogni componente composto.
- Una **demo live** — una dashboard di amministrazione completa costruita interamente con questo kit.

## Dove andare ora

- [Installazione](/docs/installation) — aggiungi il pacchetto e il suo CSS alla tua app.
- [Componenti](/docs/components) — il riferimento completo, con esempi live.
